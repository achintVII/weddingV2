# Achint & Harshita · Wedding Invitation (24 November)

Invite for guests attending the 24 November 2026 functions: The Day We Say Forever and Cheers with Dears, at Spara Boutique Resort by Chhabara Farms.

Everything lives in `index.html`: photos, fonts and animations are built in, so there are no other files to upload.

## Publish with GitHub Pages
1. Open the repository's Settings, then Pages.
2. Under Build and deployment, choose "Deploy from a branch", select `main` and `/ (root)`, and save.
3. After a minute or two the site is live at https://achintvii.github.io/weddingV2/

## Update the invite
Replace `index.html` with the new version (Add file → Upload files) and commit. The live site refreshes within a few minutes.
